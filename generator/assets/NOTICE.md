# Assets

- `styles/theme.css`, `styles/kit.css`: copied unchanged from the private source monorepo
  (same author, MIT licence, see ../../LICENSE; shadcn neutral theme, `--radius` corner token, kit base layer).
  Default skin only here; the other skins are in `skins.css` (below).
- `site.src.css`: Tailwind v4 entry (scans `../templates` and `app.js`).
- `site.css`: **built** from `site.src.css` with `@tailwindcss/cli` (`bun run site:css`) and committed so that
  `go run` needs no Node. Rebuild after changing templates.
- `app.js`: vanilla JS (code tabs, copy buttons, search). No dependencies, no network except the same-origin `search-index.json`.
- `skins.css`: generated by `scripts/gen-skins.mjs` from the ui8kit skin sources; 14 of the 15 skins are built-in presets of
  **tweakcn** (Sahaj Jain and contributors, <https://github.com/jnsahaj/tweakcn>, commit a3b47b3), Apache License 2.0
  (<https://www.apache.org/licenses/LICENSE-2.0>); only colour tokens and radius are used (changed: radius snapped to the 8px step, system fonts,
  contrast adjustments of syntax tokens and destructive in the "site overrides" section). `sky` is ui8kit's own. `skins.json` lists them for the picker.
- `theme.js`: colour mode and skin (localStorage), loaded in `<head>`.
