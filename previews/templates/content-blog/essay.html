Why pages should start from data

Why start with the data

A page that reads one source stays correct when the source changes. Everything else is layout, and layout is cheap to change.

Compose from blocks

Each block names its axes and its variants. A page is a list of blocks, so a new page is a few lines of data.

Pages are lists, not copies.

Check what you ship

Checks read the same specs as the generator, so a page cannot drift from its source without failing the build.
