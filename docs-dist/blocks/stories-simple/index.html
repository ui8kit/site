    Stories Simple

    The heading, one paragraph and the stories as a list (a cover, the title as a link, a line): cards in two or three columns, or compact rows on a card surface.

    Install

    npx ui8kit add stories-simple

    Pulls in: block, compose, container, kit-box, kit-link, kit-text, link, list, list-item, media-frame, stack, text, title, utils
