    Figure Simple

    One large picture with its caption (a title, a line, the credit): wide with the caption under it, or the caption at the side.

    Install

    npx ui8kit add figure-simple

    Pulls in: block, box, compose, container, kit-box, kit-text, media-frame, stack, text, utils

    Preview

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
