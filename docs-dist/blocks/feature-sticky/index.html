    block / marketing

    Feature Sticky

    A picture that stays in view beside a list of features. Following the section being read is a port contract (ScrollSpy).

    Install

    npx ui8kit add feature-sticky

    Pulls in: box, feature-grid, grid, lucide-icon, media-frame, section-frame, stack, text, title, utils

    Preview

    Follow the story

    Fast by default

    Pages render from static data and ship little script.

    Clear structure

    One heading per page, landmarks and a skip link come built in.

    Safe forms

    Inputs carry labels and errors are announced to assistive tools.

    Ready for any language

    Every text lives in a dictionary, so a new language is one more file.
