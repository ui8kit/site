    Site Header

    Skip link, brand, navigation, theme button and an optional call to action.

    Install

    npx ui8kit add site-header

    Pulls in: block, button, container, group, link, link-plain, utils

    Props

    Names and types come from the xgen specs of the source. Standard HTML attributes (id, role, tabIndex, aria-*) pass through to the root element; the class prop is className in React.

    The page header: a skip link to the main content, the brand, the two navigation links (the current one carries aria-current) and the theme button. `current` is the route area. Axes: layout (inline, stacked), position (static, sticky), actions (none, cta).

    Props of SiteHeader
    PropTypeDefault Description
    labels (required)SiteHeaderLabels-
    current (required)string-the area of the current route: home or pricing
    layout "inline" | "stacked""inline"inline: brand left, links and button right; stacked: all centered in rows
    position "static" | "sticky""static"sticky: stays at the top while the page scrolls
    actions "none" | "cta""none"cta: a call-to-action button after the navigation
    cta string-text of the call to action
