    Feature Accordion

    Features as a list of disclosures, the first one open, with an optional picture.

    Install

    npx ui8kit add feature-accordion

    Pulls in: disclosure, feature-grid, inline, lucide-icon, media-frame, section-frame, stack, text, utils

    Preview

    Questions about the features

    Fast by default

    Pages render from static data and ship little script.

    Clear structure

    One heading per page, landmarks and a skip link come built in.

    Safe forms

    Inputs carry labels and errors are announced to assistive tools.

    Ready for any language

    Every text lives in a dictionary, so a new language is one more file.
