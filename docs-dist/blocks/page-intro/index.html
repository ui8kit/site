    Page Intro

    The head of an inner page: the heading, one sentence and an optional action.

    Install

    npx ui8kit add page-intro

    Pulls in: action-group, section-frame, utils

    Preview

    A page title

    One sentence that says what this page is for.

// The head of an inner page: the heading (h1 on a page of its own), one sentence and, optionally, an action. Axes: align (start, center), tone, density.
