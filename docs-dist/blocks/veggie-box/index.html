    Veggie Box

    Fill a box by weight: produce tiles beside the box with a meter.

    Install

    npx ui8kit add veggie-box

    Pulls in: box, button, compose, dish-showcase, empty-state, group, inline, kit-box, kit-button, kit-label, kit-meter, kit-text, label, lucide-icon, media-frame, meter, number-field, section-frame, stack, text, utils
