    Faq Split

    Questions beside the heading, a help card, a picture or a finder, or as cards in three or four columns.

    Install

    npx ui8kit add faq-split

    Pulls in: box, button, faq-cards, faq-disclosures, faq-finder, faq-help, faq-list, feature-grid, media-frame, section-frame, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add faq-split
