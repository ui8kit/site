    Auth Layout

    A whole sign-in page: the card beside a picture panel, on a tinted page, or alone; with any mode of the card.

    Install

    npx ui8kit add auth-layout

    Pulls in: auth-card, block, box, container, grid, media-frame, stack, text, title, utils
