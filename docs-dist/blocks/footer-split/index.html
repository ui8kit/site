    Footer Split

    The brand with figures and a sitemap link over link-group cards; or a split beside a picture with points, link columns, a newsletter card, the contacts or the community channels.

    Install

    npx ui8kit add footer-split

    Pulls in: action-group, block, box, container, feature-grid, footer-brand, footer-channels, footer-contacts, footer-figures, footer-group-cards, footer-link-columns, footer-points, footer-signup-card, group, link, lucide-icon, media-frame, mega-menu, stack, stats-band, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add footer-split
