    Cookie Banner

    A consent notice with accept and decline buttons.

    Install

    npx ui8kit add cookie-banner

    Pulls in: block, box, button, container, group, lucide-icon, stack, text, title, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add cookie-banner
