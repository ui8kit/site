    block / marketing

    Before After

    Two sides of the same points: how it was and how it is, as two cards or as rows.

    Install

    npx ui8kit add before-after

    Pulls in: card, grid, group, list, lucide-icon, section-frame, stack, text, title, utils

    Preview

    Before and after

    Before

    • Weeks of wiring

    • Copied by hand

    • Colors set one by one

    • Review by eye

    After

    • One command

    • Composed from blocks

    • Tokens shared by every block

    • Automatic on every build

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add before-after
