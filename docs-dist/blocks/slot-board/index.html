    Slot Board

    Days with their delivery windows as radio chips, beside the zone card.

    Install

    npx ui8kit add slot-board

    Pulls in: box, button, field, inline, list, section-frame, select, slot-grid, stack, text, utils, zone-table

    Preview

    Pick a delivery window

    Windows close two hours before they start.

    Today, 8 October

    2 windows left

    Tomorrow, 9 October

    6 windows

    • Delivery$12
    • Free from$75
    • Time90 minutes

    The courier calls ten minutes before arriving.

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add slot-board
