    Feature Split

    Features beside a picture: plain in two columns, as cards with actions, two figures over checked rows, or four metric cards with actions.

    Install

    npx ui8kit add feature-split

    Pulls in: action-group, error-page, feature-cards, feature-grid, feature-metric-cards, feature-pairs, feature-stat-rows, media-frame, section-frame, stats-band, utils

    Preview

    Features

    Built for teams that ship

    Everything you need to plan, build and publish, in one place.

    Fast by default

    Pages render from static data and ship little script.

    Clear structure

    One heading per page, landmarks and a skip link come built in.

    Safe forms

    Inputs carry labels and errors are announced to assistive tools.

    Ready for any language

    Every text lives in a dictionary, so a new language is one more file.
