    Post Showcase

    Four small post cards beside an intro with a view-all link; the first post in detail beside its picture; or cards with the text on a panel over the picture, in two or three columns.

    Install

    npx ui8kit add post-showcase

    Pulls in: box, link, lucide-icon, media-frame, post-card, post-feature, post-mini-card, post-overlay-card, section-frame, utils

    Code

    Svelte

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
