    Header Simple

    The brand as the link home, the navigation links and one action in a bar: the links in the middle, at the end beside the action, or centred under the brand. No menu button: the links wrap on a narrow screen.

    Install

    npx ui8kit add header-simple

    Pulls in: block, box, compose, container, group, kit-box, kit-link, kit-text, link-button, link-plain, list, list-item, text, utils
