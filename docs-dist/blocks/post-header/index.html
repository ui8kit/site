    Post Header

    Category, title, excerpt, author line and a wide cover.

    Install

    npx ui8kit add post-header

    Pulls in: group, media-frame, pill, post-card, section-frame, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add post-header

export function PostHeader({
