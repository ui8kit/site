    Dish Card

    A dish as a card: picture, category, portion/weight, price and an order button. No rating.

    Install

    npx ui8kit add dish-card

    Pulls in: badge, block, box, button, card-content, compose, dish-showcase, group, kit-box, kit-button, kit-link, kit-text, link, media-frame, text, title, utils
