    Hero Prompt

    Heading, lead, one or two actions and optional media.

    Install

    npx ui8kit add hero-prompt

    Pulls in: action-group, block, container, cta-actions, hero-badge, hero-head, nav-bar, presets, prompt-composer, stack, topic-chips, utils, weighted-title

    Preview

    No static preview for this item: it needs content or a parent that this page cannot supply. The code is below.

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add hero-prompt
