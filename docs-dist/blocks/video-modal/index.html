    Video Modal

    A dialog with a walkthrough video and an optional list of chapters. Opening and playing are port contracts.

    Install

    npx ui8kit add video-modal

    Pulls in: box, button, group, list, lucide-icon, media-frame, section-frame, stack, text, title, utils

    Preview

    Watch the walkthrough

    A three-minute tour of the editor.
