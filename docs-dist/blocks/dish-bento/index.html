    Dish Bento

    One featured dish in a large tile among smaller ones.

    Install

    npx ui8kit add dish-bento

    Pulls in: add-icon, badge, box, compose, dish-showcase, empty-state, group, inline, kit-box, kit-link, kit-text, link, lucide-icon, media-frame, section-frame, stack, text, title, utils
