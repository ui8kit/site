    Store Hero

    The hero of a store with promises under the actions, beside a picture with an offer card or over a faint picture.

    Install

    npx ui8kit add store-hero

    Pulls in: action-group, backdrop, box, error-page, feature-grid, grid, group, lucide-icon, offer-media, section-frame, stack, text, utils
