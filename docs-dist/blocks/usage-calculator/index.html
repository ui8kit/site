    Usage Calculator

    A slider for how much is used and the price it gives. The estimate follows the slider; the page keeps the value.

    Install

    npx ui8kit add usage-calculator

    Pulls in: button, group, range, section-frame, stack, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add usage-calculator
