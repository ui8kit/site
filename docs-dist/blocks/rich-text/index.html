    Rich Text

    The body of the current page or post as rich text (headings, lists, quotes, pictures, code, tables) under its title and a meta line; in a reading column, wide, beside a side note, under a cover, in a card, or as the page heading over a wide cover.

    Install

    npx ui8kit add rich-text

    Pulls in: box, card, compose, grid, group, kit-box, kit-text, media-frame, pill, prose, section-frame, text, title, utils

    Preview

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add rich-text
