    Announcement Bar

    A thin strip above the page with one sentence and a link.

    Install

    npx ui8kit add announcement-bar

    Pulls in: block, button, container, group, inline, link-plain, lucide-icon, text, utils

    Preview

    New: dark mode for every block.

    See what is new

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add announcement-bar
