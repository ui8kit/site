    Hero Split

    A split hero with figures, faces, small cards or a quote under the lead, beside a picture, a floating card, a picture grid or plan cards.

    Install

    npx ui8kit add hero-split

    Pulls in: action-group, error-page, feature-grid, hero-split-extras, hero-split-media, pricing-card, section-frame, stats-band, store-hero, testimonial-grid, utils
