    Page Trail

    Breadcrumbs over the badge, the heading and the lead; with one large figure, a note card or four key facts at the end.

    Install

    npx ui8kit add page-trail

    Pulls in: block, box, container, nav-bar, page-aside, page-crumbs, section-header, stack, stats-band, utils
