    Product Detail

    The gallery and the buy box of one product.

    Install

    npx ui8kit add product-detail

    Pulls in: badge, button, grid, group, inline, list, lucide-icon, media-frame, number-field, product-card, rating, section-frame, stack, text, utils

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
