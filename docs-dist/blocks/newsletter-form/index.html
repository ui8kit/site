    Newsletter Form

    An email field and a button, inline, stacked or beside a picture.

    Install

    npx ui8kit add newsletter-form

    Pulls in: button, form, group, input, label, media-frame, section-frame, text, utils

    Preview

    Get the monthly digest

    One short email a month with new blocks, guides and releases.

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn

export function NewsletterForm({
