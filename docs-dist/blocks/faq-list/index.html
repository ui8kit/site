    Faq List

    Questions as native disclosures.

    Install

    npx ui8kit add faq-list

    Pulls in: box, disclosure, grid, search-field, section-frame, stack, switcher, switcher-item, text, utils

    Preview

    Questions

    Is there a free plan?

    Yes. Solo is free and has no time limit.

    Can I change plans later?

    You can move up or down at any time; the change applies to the next month.

    Can I export my data?

    Every plan can export all content as files.

    How fast is support?

    Team answers within one working day, Scale within four hours.
