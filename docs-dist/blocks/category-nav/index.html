    Category Nav

    Categories as chips, a bar, a side list, tiles, or chips under a toolbar.

    Install

    npx ui8kit add category-nav

    Pulls in: block, container, group, inline, link, list, lucide-icon, search-field, select, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add category-nav
