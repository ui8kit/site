    Milestone Timeline

    Milestones on a vertical line beside a picture, in a narrow column, or in a row.

    Install

    npx ui8kit add milestone-timeline

    Pulls in: badge, group, inline, list, media-frame, section-frame, text, title, utils

    Preview

    Our story so far

    From a list of blocks to a kit in three runtimes.

    1. 2021

      Start

      The first commit

      Two people, one laptop and a list of blocks they kept rebuilding.

    2. 2022

      Release

      Public launch

      The kit goes public with forty blocks and one runtime.

    3. 2024

      Release

      Three runtimes

      Svelte, React and Vue from the same specs, file for file.

    4. 2026

      Team

      A team of twenty

      Offices in three cities and a support desk that answers within the hour.
