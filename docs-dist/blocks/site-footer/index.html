import { type ReactNode } from "react";

  layout = "minimal",
  density = "default",
  landmarkLabel,

          (((layout as string) === "centered") ? "flex-col text-center" : "justify-between")
        )}
        data-slot="container"
      >
        <Text size="sm" className="text-muted-foreground" data-testid="copyright">
          {labels.copyright}
        </Text>

            </Link>
            <Link href="#/pricing" variant="default">
              {labels.pricing}
            </Link>
          </Group>
        </NavBlock>
      </Container>
    </Block>
  );
}

    Names and types come from the xgen specs of the source. Standard HTML attributes (id, role, tabIndex, aria-*) pass through to the root element; the class prop is className in React.

    The page footer: the copyright line and the same two links. Axes: layout (minimal, centered), density (default, compact).

    Props of SiteFooter
    PropTypeDefault Description
    labels (required)SiteFooterLabels-
    layout "minimal" | "centered""minimal"minimal: one row; centered: stacked and centered
    density "default" | "compact""default"
    landmarkLabel string-accessible name of the landmark of this component when the page shows it more than once (a variant); replaces the heading name of the root landmark, follows the name of a nested one
