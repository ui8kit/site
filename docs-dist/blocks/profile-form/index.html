    block / account

    Profile Form

    Account settings: picture, name, email, bio and notifications.

    Install

    npx ui8kit add profile-form

    Pulls in: button, container, field, form, grid, group, input, label, media-frame, panel, stack, switch, textarea, title, utils

    Preview

    Profile

    Your name and email appear on invoices and in comments.

    Notifications

    Code

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add profile-form
