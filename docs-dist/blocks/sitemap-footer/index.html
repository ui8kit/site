    Sitemap Footer

    A footer with the brand, groups of links and the copyright; a single row, a sign-up first or a status pill.

    Install

    npx ui8kit add sitemap-footer

    Pulls in: block, box, button, container, footer-card, footer-columns, form, group, input, label, link, mega-menu, nav-block, pill, stack, text, title, utils
