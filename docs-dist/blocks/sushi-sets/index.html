    Sushi Sets

    A dense grid of sets with the piece count and the rolls of each.

    Install

    npx ui8kit add sushi-sets

    Pulls in: add-icon, badge, box, compose, dish-showcase, empty-state, grid, group, inline, kit-box, kit-text, list, list-item, lucide-icon, media-frame, section-frame, stack, text, utils

export function SushiSets({
  id,
  title,

  empty = "",
