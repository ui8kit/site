    Sidebar Nav

    A vertical navigation with the brand on top and the user at the bottom: full, or icons only.

    Install

    npx ui8kit add sidebar-nav

    Pulls in: block, group, inline, link, list, lucide-icon, media-frame, nav-bar, stack, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add sidebar-nav
