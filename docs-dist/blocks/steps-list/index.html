    Steps List

    Numbered or icon steps in a row or a column.

    Install

    npx ui8kit add steps-list

    Pulls in: iconbadge, inline, list, lucide-icon, section-frame, stack, text, title, utils

    Preview

    How it works

    1. 1

      Pick a plan

      Start free and upgrade when the team grows.

    2. 2

      Connect your data

      Point the site at your collections and content.

    3. 3

      Choose the blocks

      Compose pages from ready blocks and variants.

    4. 4

      Publish

      Ship to every runtime with one command.
