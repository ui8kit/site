    Steps List

    Numbered or icon steps in a row or a column.

    Install

    npx ui8kit add steps-list

    Pulls in: iconbadge, list, lucide-icon, section-frame, stack, text, title, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add steps-list
