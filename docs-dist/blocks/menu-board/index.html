    Menu Board

    Category sections with DishCards in a grid, or denser menu rows; prices can be hidden.

    Install

    npx ui8kit add menu-board

    Pulls in: box, compose, dish-card, dish-showcase, empty-state, grid, kit-box, kit-text, list, menu-row, menu-section-nav, restaurant-menu, section-frame, stack, text, title, utils
