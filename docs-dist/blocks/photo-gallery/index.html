    Photo Gallery

    Photos in a grid, a masonry, a mosaic, a featured picture with thumbnails, or cards.

    Install

    npx ui8kit add photo-gallery

    Pulls in: badge, block, box, button, group, lucide-icon, media-frame, section-frame, stack, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add photo-gallery
