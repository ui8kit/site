    block / marketing

    Proof Band

    A bar of customer logos and a row of key figures together.

    Install

    npx ui8kit add proof-band

    Pulls in: grid, group, logo-cloud, lucide-icon, section-frame, stack, stats-band, text, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add proof-band
