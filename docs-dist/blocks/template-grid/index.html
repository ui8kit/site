    Template Grid

    Template gallery: filters, a browse-all button and an 8-card MediaFrame grid.

    Install

    npx ui8kit add template-grid

    Pulls in: box, button, grid, group, iconbadge, lucide-icon, media-frame, presets, section-frame, stack, text, title, utils

    Code

    Svelte

    Point the CLI at this runtime once, then add the item:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add template-grid
