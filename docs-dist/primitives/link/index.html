    Props

    Names and types come from the xgen specs of the source. Standard HTML attributes (id, role, tabIndex, aria-*) pass through to the root element; the class prop is className in React.

    Link renders an anchor; External opens a new tab with rel=noopener noreferrer.

    Props of Link
    PropTypeDefault Description
    target string-explicit target; External implies _blank
    rel string-explicit rel; External defaults to noopener noreferrer
    external boolean-opens in a new tab with safe rel defaults
