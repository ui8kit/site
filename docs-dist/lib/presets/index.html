    Presets

    Default layout preset: the sizes of the landing blocks as Tailwind classes. Blocks combine these with token classes; swap the preset to resize every block at once. Numbers: ui8kit default sizes (Tailwind scale, no arbitrary values)

    Install

    npx ui8kit add presets

    Pulls in: utils
