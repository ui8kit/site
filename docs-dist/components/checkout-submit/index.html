    Checkout Submit

    Checkout Submit component

    Install

    npx ui8kit add checkout-submit

    Pulls in: button, checkbox, group, label, stack, text, utils

    Preview

    By placing the order you confirm the address and the window.

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
