    Names and types come from the xgen specs of the source. Standard HTML attributes (id, role, tabIndex, aria-*) pass through to the root element; the class prop is className in React.

    A page section: the landmark named by its heading, the heading (h1 or h2), an optional lead, the body (`children`) and optional media. `layout` stacks everything or puts the media beside the text; `boxed` puts the body in a card. Axes: layout, media side, tone, density, align.

    Props of SectionFrame
    PropTypeDefault Description
    id (required)string-ties the heading to the section: the heading id is `<id>-title`
    title string""section heading; empty string: no heading
    lead string-text under the heading
