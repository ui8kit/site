    Support: FAQ

    3 sections between the top bar and the footer of the template.

    Install

    The blocks of this page, top bar and footer included:

    npx ui8kit add nav-bar page-intro faq-list sitemap-footer

    Blocks: nav-bar, page-intro, faq-list, sitemap-footer

    Point the CLI at this runtime once, then add the blocks:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add nav-bar page-intro faq-list sitemap-footer
