    Online shop: Cart

    4 sections between the top bar and the footer of the template.

    Install

    The blocks of this page, top bar and footer included:

    npx ui8kit add nav-bar page-intro shopping-cart cart-list order-summary sitemap-footer

    Blocks: nav-bar, page-intro, shopping-cart, cart-list, order-summary, sitemap-footer

    The page as generated in the source monorepo (commit 6c20aba1e4be). It imports the blocks from the UI package and its texts and sample data from the app package; after installing the blocks, replace those imports with your own content.

    Point the CLI at this runtime once, then add the blocks:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add nav-bar page-intro shopping-cart cart-list order-summary sitemap-footer
