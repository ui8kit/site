    npx ui8kit add nav-bar page-intro category-nav product-grid sitemap-footer

    The page as generated in the source monorepo (commit 8efbb7e81376). It imports the blocks from the UI package and its texts and sample data from the app package; after installing the blocks, replace those imports with your own content.

    Point the CLI at this runtime once, then add the blocks:

    npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
    npx ui8kit add nav-bar page-intro category-nav product-grid sitemap-footer
