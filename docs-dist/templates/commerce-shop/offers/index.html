    Online shop: Offers

    4 sections between the top bar and the footer of the template.

    Install

    The blocks of this page, top bar and footer included:

    npx ui8kit add nav-bar store-hero usp-strip product-grid cart-drawer sitemap-footer

    Blocks: nav-bar, store-hero, usp-strip, product-grid, cart-drawer, sitemap-footer
