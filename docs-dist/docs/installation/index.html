    Installation

    Registry roots

    Runtime registryUrl
    Svelte 5 https://registry.buildy.tw/svelte
    React 19 https://registry.buildy.tw/react
    Vue 3 https://registry.buildy.tw/vue

    The URL is the base the CLI appends index.json and components/ui/<name>.json to. Use --strict-cdn so the CLI never falls back to the public CDN.

    What lands where

    Files are written under your dir (for example src) with the same layout as the ui8kit packages:

    Registry type Folder
    registry:utils utils/ (cn, variants, expr, a11y helpers)
    registry:lib presets/ (size presets shared by blocks)
    registry:ui primitives/<name>/
    registry:component components/
    registry:block blocks/

    Pick the framework, not a file filter

    Pass --framework svelte, react or vue together with the matching registry URL. The registry is already split per runtime, and with ui8kit 2.0.2 the CLI installs the *.types.ts files that blocks import, so add --all leaves no unresolved relative import.

    npx ui8kit init --yes --framework react --dir src --registry-url https://registry.buildy.tw/react --strict-cdn
npx ui8kit add button card hero-split
