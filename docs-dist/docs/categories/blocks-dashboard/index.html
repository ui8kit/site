    Blocks: dashboard

    Widgets, navigation, layouts and empty or error states for app dashboards.

    Every item below has Svelte, React and Vue code and an install command. Install one with npx ui8kit add <name>.

    Items

    • Activity Feed

      block / dashboard

      Recent events as a timeline or a list.

    • App Shell

      block / dashboard

      The frame of a signed-in app with a first screen: a sidebar, a top bar, or three panes.

    • Bottom Nav

      block / dashboard

      An app-style tab bar for a phone: an icon over a name, the current tab marked.

    • Chart Panel

      block / dashboard

      Orders per day as bars or meters.

    • Dashboard Overview

      block / dashboard

      Counters, a chart and recent activity in one section.

    • Dashboard Shell

      block / dashboard

      Twelve frames of a signed-in app around empty cards: a top bar across the shell or over the content, with or without search; a wide, rail, collapsed, two-level or no sidebar, at the start or the end; a footer across the shell, under the content or none.

    • Empty Panel

      block / dashboard

      A list with nothing in it, with an optional action.

    • Kanban Board

      block / dashboard

      Work items in lanes with a count; cards with a tag and a person. Moving cards is a port contract (SortableList).

    • Metric Row

      block / dashboard

      Key counters of a dashboard.

    • Sidebar Nav

      block / dashboard

      A vertical navigation with the brand on top and the user at the bottom: full, or icons only.

    • Skeleton Layout

      block / dashboard

      Grey blocks in the shape of what is coming: cards, a list or an article.
